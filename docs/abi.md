# Module ABI `cgp.abi/1`

A portable module is a WebAssembly binary. The host copies UTF-8 JSON in and copies UTF-8 JSON out. It does not share the guest memory with another module or with the host's objects.

The guest exports:

| Export | Signature | Role |
| --- | --- | --- |
| `memory` | pages of 65536 bytes, with a maximum | Private linear memory. No maximum, or a maximum above the policy, is refused before instantiation. |
| `cg_alloc` | `(n: i32) -> i32` | Space for the host's input. `0` means the guest cannot take those bytes. |
| `cg_hook` | `(hook: i32, ptr: i32, len: i32) -> i32` | `0` on success. Any other status is a failure. The message is the output bytes. |
| `cg_out_ptr` | `() -> i32` | Start of the result. |
| `cg_out_len` | `() -> i32` | Length of the result. Empty means `undefined`. |

Hook numbers: `0` register, `1` initialize, `2` shutdown, `3` exportState, `4` importState, `5` call.

Register may return `{ "contributions": [{ "slotId", "id", "payload", "dispatch": true }] }`. `dispatch: true` on the contribution replaces the payload with an ABI handle. The handle's enumerable fields are `{ "abi": "cgp.abi/1", "moduleId", "contributionId" }`. Those fields are not the capability. The host mints the object for the composition that is registering the guest, and only that session will call it. A JSON value with the same fields, a copy made with `JSON.parse(JSON.stringify(handle))`, and a handle minted for another composition do not run the guest. The copy is not callable. The foreign handle fails with `ABI handle belongs to another composition.` A nested object whose only own key is `dispatch: true` becomes a handle for that same module and contribution, not for a module id written in the JSON. Guest JSON is copied onto fresh objects. A `__proto__` or `constructor` field stays data. It does not change `Object.prototype`, and an inherited `dispatch` is not a marker.

A register result that is not JSON, or whose `contributions` value is not an array of plain objects with an own string slot and id, fails the hook and stops that guest. A later call is hook `5`. The input JSON is `{ "contributionId", "arg", "args" }`. A call with no arguments is valid and sends `"arg": null` and `"args": []`. That null means the argument list was empty. An explicit null is `"arg": null` and `"args": [null]`. An explicit `undefined`, including a one-element list of `undefined`, is refused before the guest runs. The output is JSON. Empty output is `undefined`. Values that are not JSON data are refused before the guest runs: `undefined`, functions, symbols, bigints, non-finite numbers, class instances, and circular references. If reading the value throws, including a getter or a non-enumerable `toJSON`, the failure is `ABI payload is not JSON (could not encode).` The thrown value is not forwarded. That refusal is a failed call or a failed import, and it does not by itself stop the guest. The admission count still drops, so release can finish.

The only import the host will link is `cgp.abi.log` `(ptr, len)`, and only when the manifest lists `cgp.log` and the policy's `allowCapabilities` includes it. `wasi_snapshot_preview1`, `node:fs`, and every other import are refused before the guest runs. Shared memory, 64-bit memory, and a missing memory maximum are refused. A table must declare a maximum of at most 256 entries.

The host does not run the guest on its own thread and does not block that thread. Guest memory must declare a maximum at or below `maxMemoryBytes`. The file size is a separate limit, `maxBinaryBytes`. A binary larger than the linear memory is allowed only when the binary limit says so. The worker repeats both checks. Each composition owns the workers it opens. `release` resolves after those workers have been terminated, including a worker that was still loading and including when shutdown throws. A reservation is refunded once. `shutdown` is single-flight. `dispose` ends every session on that backend. Two compositions do not share a guest, even when they load the same module id at different versions. Aggregate budgets (`maxGuests`, `maxTotalMemoryBytes`, `maxTotalBinaryBytes`, `maxTotalHookMs`) are per composition. Host ceilings are per backend. Host memory is the sum of declared linear-memory maxima, including in-flight loads, and it does not include `isolateHeapMb`. Unset means unlimited. When a hook-time budget is set, that ledger admits one call at a time; an in-flight call can exceed it, and the next call observes the spent time. `cgp.log` output is capped in UTF-8 bytes and stored on the composition that produced it. Completed compositions keep a bounded number of those logs. The browser isolate enforces these same rules. It refuses `isolateHeapMb` because a page cannot cap a worker heap. The Node isolate applies that cap. Copy `examples/wasm-module` or `examples/third-party-module` to start a guest. `scripts/check-wasm-module.ts` instantiates a package that was not built in this repository. `org.cgp.dune-growth` is a guest that contributes a real policy.

The in-process backend does not speak this ABI. It is an explicit opt-in that still cannot enforce these limits. `createCrossBackend` routes a handle minted for that composition to its isolate session, and routes a JSON lookalike to the in-process half, which does not call it. A handle from another composition is refused before either guest runs. JavaScript functions go to the in-process backend. The JavaScript half is still not limited. Copy `examples/wasm-module` to start a guest. `org.cgp.dune-growth` is a guest that contributes a real policy.
